# Demomallar

Filerna här är **testfiler från Rives öppna runtime** ([rive-app/rive-runtime](https://github.com/rive-app/rive-runtime),
`tests/unit_tests/assets`, MIT-licens © 2020 Rive). De används bara för att visa hur mallbiblioteket fungerar
och ska ersättas med egna mallar.

`index.json` listar mallarna. Varje post pekar ut en `.riv`-fil och en artboard, och kan valfritt
byta namn på, sortera eller dölja fälten som annars läses automatiskt från artboardens View Model.
Se `docs/mallar.md` i projektroten för hur en mall byggs i Rive.
